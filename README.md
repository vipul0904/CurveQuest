# 🎮 CurveQuest

**CurveQuest** is a math and physics canvas puzzle platformer where equations become platforms! Type mathematical functions (e.g., `y = 2*x + 1`, `y = sin(x) + 5`, `y = 0.1*(x-3)^2 + 1`) to construct solid curves in real-time, navigate hazards, collect coins, and solve challenging levels.

---

## 🕹️ Game Modes

- **🪙 Coin Rush**: Race against the clock to collect as many coins as possible. Watch out for slimes and bats!
- **⚽ Soccer**: Use curves to guide and push the blue ball into silver targets.
- **🧩 Puzzle**: 5 progression levels where you must collect all required coins and reach the goal flag while adhering to level rules and dodging enemies (Slimes, Bats, and Graph Eaters!).
- **🎓 Tutorial**: Interactive 6-step guided walkthrough covering movement, curve editing, jumping, and dodging.

---

## ⌨️ Controls

| Key | Action |
| --- | --- |
| <kbd>A</kbd> / <kbd>D</kbd> or <kbd>←</kbd> / <kbd>→</kbd> | Move Left / Right |
| <kbd>Space</kbd> | Jump |
| <kbd>S</kbd> / <kbd>↓</kbd> | Crouch (Hold direction to Slide) |
| <kbd>Tab</kbd> | Open / Close Graph Editor |
| <kbd>↑</kbd> / <kbd>↓</kbd> *(in Editor)* | Switch between Graph 1 and Graph 2 |
| <kbd>Enter</kbd> *(in Editor)* | Apply equation |
| <kbd>Space</kbd> *(in Editor)* | Clear equation |
| <kbd>P</kbd> or <kbd>Esc</kbd> | Pause / Resume game |
| <kbd>R</kbd> | Reset Ball position (Soccer mode) |

---

## 📐 Supported Math Functions & Syntax

- Basic operations: `+`, `-`, `*`, `/`, `^` (power)
- Variables & Constants: `x`, `pi`, `e`
- Functions: `sin(x)`, `cos(x)`, `tan(x)`, `sqrt(x)`, `abs(x)`, `ln(x)`, `exp(x)`
- Implicit multiplication support (e.g., `2x` or `(x-3)^2`)
